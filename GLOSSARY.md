# Rides dashboard

Daily ride counts for a set of cities, summarised for display on a static site.

## Language

**Ride count**:
The number of rides in one city on one date.
_Avoid_: Rides (when meaning a single day's figure), volume, trips

**Busiest day**:
For one city, the date with the highest ride count; when several dates tie, the earliest of them.
_Avoid_: Peak day, top day, max day
